# 希伯来圣经 · 中文译本

逐节翻译的希伯来圣经，紧贴原文的字句。

## 以希伯来文为本

这部译本的存在，是为引你走近希伯来原文，而非取而代之。所读的始终是
希伯来文——它的辅音、元音符号与诵读记号；下方的中文只是一扇窗，不是
替代。凡中文与原文看似有出入之处，以希伯来文为准。

## 圣名

凡神那四个字母的名出现之处，我们译作 **雅威**——按其读音写出，而不以
称谓或加了元音的形式代替。我们不采用传统的「耶和华」，而是让这名的声
音进入中文。圣名在每一处都保持为圣名，使你在页面上总能认出它的所在。

## את（阿列夫-塔夫）

你会看到译文中保留着 **⟨את⟩**。在希伯来文里，אֵת 是一个小词，标记确定
的直接宾语——它指向动作所及的对象，在中文里没有对应的词，因此多数译
本悄然略去。我们将它以括号保留，因为它是句子结构的一部分；与其默默抹
去，我们宁愿让你看见它就在那里。

## ⟨方括号⟩中的词

尖括号 ⟨如此⟩ 标出的，是**希伯来文中没有、而中文行文所需**的词——那些
希伯来文略而不言的系词、冠词与连接词。我们不将它们不着痕迹地融入，而
是加上括号，好让希伯来文本有的字句，与中文所补的字句，始终分得清楚。

## 名号与称谓

凡希伯来文以自己的词称呼神之处——**以罗欣**（Elohim）、**以勒**（El）、
**沙代**（Shaddai）、**阿多奈**（Adonai）——我们保留其原貌，按读音译出，
而不一律译作「神」。每一个都在原文中自有其分量；保留它们，你便能看出
经文实际用的是哪一个。

## 各节独立成义

每一节都按其所在之处的字句翻译——依希伯来文严格的一神信仰来读，独一
的神——不掺入后世的教义，也不将故事的结局倒读回它的开端。用意是让字
句在其本处，各说各的本意。

## 文本的形式

每节一份文件：经文本身，以及与希伯来文逐词对齐的译文，使每个希伯来词
都能与它的中文相互对照。
